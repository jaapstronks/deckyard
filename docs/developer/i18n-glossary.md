# Locale glossary

This is the canonical source for reviewed locale terminology and style. Each locale below has forty-four reviewed concepts (seven analytics concepts, four configuration/type/shape concepts, four short labels whose form agrees with an implied noun: Dark, Light, All, None, and twelve typography, alignment and theme labels: Fonts, Italic, Weight, Normal, Left, Right, Soft, Primary, Default, Original, Style, Background, and six trash and removal labels: Move "{title}" to trash?, Move to trash, Delete, Restore, Remove, Remove row, and eight sharing and role concepts: Share, Export, Publish, Published, Unpublish, Can comment, Can edit, Owner, and three access-lifetime concepts: Revoke, Never expires, This share link has expired.); these entries do not claim a review of the rest of that locale.

Where a language distinguishes them, three rules split one English label: **position versus alignment** (where something sits, such as the image focus or logo corner, against where content is aligned to), **colour name versus style option** (a colour picker names a colour noun, a button style is an adjective), and **agreement with the row noun** (an option agrees with the noun of the row it sits in, like its siblings). A locale that does not make the distinction keeps one form.

Two rules keep two English labels apart. **Move to trash versus delete permanently**: moving a deck or slide to the trash can be undone, so its label and confirmation use the trash wording and never the word of Delete; only Delete permanently promises irreversibility. **Remove versus delete**, where the language has both words: Remove takes something out of a collection and the thing stays (es Quitar, fr Retirer, sv Ta bort), Delete destroys it (es Eliminar, fr Supprimer, sv Radera).

The analytics title names the same feature on the dashboard, in deck settings and in instance administration. The chart description is the accessible name of both views-over-time bar charts, whether rendered with CSS or SVG.

### Dutch style

Dutch here borrows English freely; don't over-translate product vocabulary.

| Use                             | Not                     |
| ------------------------------- | ----------------------- |
| slide, slides                   | dia, dia's              |
| slide-type, slide-bibliotheek   | diatype, diabibliotheek |
| reactie (a comment)             | opmerking               |
| antwoord (a reply to a comment) | reactie                 |
| organization, lead, analytics   | werkruimte, …           |
| detailregel (title slide)       | meta                    |
| kanttekening (the aside inset)  | terzijde                |
| op je telefoon (notes on phone) | notities (QR)           |

The English words for the last three rows are **Detail line**, **Side note** and **On your phone**; every locale names those concepts with one word of its own, never the schema key or the mechanism (D352).

Address the user informally (`je` / `jouw`, never `u`), use infinitives for action labels (Opslaan, Annuleren, Verwijderen), and sentence case for headings; Dutch does not capitalize every word.
