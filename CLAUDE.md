# Deckyard — agent instructions

This file holds no instructions of its own, on purpose: it only imports them,
so it does not change and a fork can replace it with its own `CLAUDE.md`
without a merge conflict every round (B426). The conventions of the code are in
`AGENTS.md`; upstream's maintainer workflow (planning, handoff, beta doctrine,
git and releases) is in `docs/developer/maintaining.md`.
